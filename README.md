### 🚀 Projects

- 🎙️ **[DevPrep](https://dev-prep-frontend.vercel.app/)** — AI-powered mock interview platform with a live voice interviewer. Runs real-time speech transcription through Groq Whisper and generates structured, criteria-based feedback with the Gemini API, while candidates write and execute code live through Judge0. Built as a pnpm monorepo on Next.js App Router, owning everything from schema design to cloud deployment.

- 🧠 **[Brainly AI](https://github.com/Furqan-7/Brainly-AI)** — A RAG-based personal knowledge assistant that turns scattered notes, PDFs, tweets, and videos into one queryable second brain. Cloud-native full-stack system with a relational schema in PostgreSQL/Prisma, JWT-secured typed REST APIs, and a dark, Framer Motion–driven UI, independently deployed to Vercel and Railway.

- 🔎 **[FindYourPortfolio](https://github.com/Furqan-7/FindYourPortfolio)** — A browsable gallery of 1,500+ real developer portfolios, sourced live from GitHub. Built to help developers find design inspiration without scrolling through endless Dribbble mockups.

- 🧮 **LeetCode** — 450+ problems solved on LeetCode, 550+ across platforms in C++. Strongest in graphs, dynamic programming, trees, and binary search.
